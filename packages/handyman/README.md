# OpenPacks — handyman Pack

**Base System**: OpenFieldPro / Dolibarr
**Pricing**: Free / Starter ($299–$599) / Managed ($9–$49/mo)

## Features
Fast quotes, calendar, on-site invoicing, price book, deposits

## Quick Install
```bash
curl -fsSL https://raw.githubusercontent.com/praveenkay/OpenpacksAI/main/packages/handyman/install.sh | bash
```

## Manual
```bash
cd packages/handyman
cp .env.example .env
docker compose up -d
```
