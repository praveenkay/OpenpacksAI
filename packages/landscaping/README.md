# OpenPacks — landscaping Pack

**Base System**: OpenFieldPro (recurring)
**Pricing**: Free / Starter ($399–$799) / Managed ($9–$49/mo)

## Features
Crew routes, recurring jobs, auto-invoicing, photo proof, weather notes

## Quick Install
```bash
curl -fsSL https://raw.githubusercontent.com/praveenkay/OpenpacksAI/main/packages/landscaping/install.sh | bash
```

## Manual
```bash
cd packages/landscaping
cp .env.example .env
docker compose up -d
```
