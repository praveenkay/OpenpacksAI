## Manual Install

1. Clone: `git clone https://github.com/praveenkay/OpenpacksAI`
2. `cd OpenpacksAI/packages/free`
3. `cp .env.example .env`
4. `docker compose up -d`
5. Visit: `http://localhost:8080`
