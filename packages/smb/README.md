# OpenPacks — smb Pack

**Base System**: Dolibarr / ERPNext / MyCompany
**Pricing**: Free / Starter ($399–$899) / Managed ($9–$49/mo)

## Features
Invoicing, CRM, inventory, projects, accounting, e-invoicing

## Quick Install
```bash
curl -fsSL https://raw.githubusercontent.com/praveenkay/OpenpacksAI/main/packages/smb/install.sh | bash
```

## Manual
```bash
cd packages/smb
cp .env.example .env
docker compose up -d
```
