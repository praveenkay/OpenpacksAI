# OpenPacks — restaurants Pack

**Base System**: URY (ERPNext) / Posnic
**Pricing**: Free / Starter ($499–$999) / Managed ($9–$49/mo)

## Features
Tables, KDS, menu, QR ordering, delivery, kitchen routing

## Quick Install
```bash
curl -fsSL https://raw.githubusercontent.com/praveenkay/OpenpacksAI/main/packages/restaurants/install.sh | bash
```

## Manual
```bash
cd packages/restaurants
cp .env.example .env
docker compose up -d
```
