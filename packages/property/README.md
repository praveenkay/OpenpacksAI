# OpenPacks — Property / Rentals Pack

**Base System**: OpenProperty (MIT)
**Pricing**: Free / Starter ($399–$799) / Managed ($9–$49/mo)

## Features
- Units, leases, rent ledger
- Maintenance work orders
- Tenant portal with photos
- Automated rent reminders
- Owner statements & accounting export
- Multi-location support

## Quick Install
```bash
curl -fsSL https://raw.githubusercontent.com/praveenkay/OpenpacksAI/main/packages/property/install.sh | bash
```

## Manual
```bash
cd packages/property
cp .env.example .env
docker compose up -d
```
