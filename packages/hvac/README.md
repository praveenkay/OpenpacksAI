# OpenPacks — HVAC / Trades Pack

**Base System**: OpenFieldPro (ERPNext Field)
**Pricing**: Free / Starter ($599–$1,199) / Managed ($9–$49/mo)

## Features
- Dispatch boards, work orders
- GPS tracking, parts inventory
- Same-day invoicing
- On-my-way customer texts
- Skill-based assignment

## Quick Install
```bash
curl -fsSL https://raw.githubusercontent.com/praveenkay/OpenpacksAI/main/packages/hvac/install.sh | bash
```
