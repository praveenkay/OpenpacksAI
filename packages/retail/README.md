# OpenPacks — retail Pack

**Base System**: Posnic / MyCompany
**Pricing**: Free / Starter ($399–$799) / Managed ($9–$49/mo)

## Features
POS + inventory, barcode, multi-register, payment terminal, reporting

## Quick Install
```bash
curl -fsSL https://raw.githubusercontent.com/praveenkay/OpenpacksAI/main/packages/retail/install.sh | bash
```

## Manual
```bash
cd packages/retail
cp .env.example .env
docker compose up -d
```
